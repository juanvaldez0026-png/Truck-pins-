TruckPins

Real-Time Mobile Vendor Discovery & Social Commerce Engine
Overview

TruckPins is a platform designed to connect mobile food vendors (food trucks) with
consumers in real-time. It solves the $2.9 billion industry's discovery problem by
allowing users to view live locations on a map, use an AI-driven craving assistant, and
participate in a social rating network.
MVP Features
• Top Rated Social Discovery: Community-driven rankings showing star ratings, total
likes, and user-uploaded food photos. Features a 24-hour "Foodie Feed" concept.
• AI Craving Assistant: Integrated AI that recommends food trucks based on natural
language text prompts (e.g.,"I want something spicy").
• Real-Time Map: Live location tracking of vendors.
• Smart Filtering: Filter by cuisine, distance, and "Open Now" status.
• Social Profiles: Simulated Google/Facebook login for user profiles.
Tech Stack
• Frontend/App: Glide (No-code functional prototype)
• Backend/Data: Google Sheets (Live database sync)
• AI Integration: Glide AI
• Maps: Integrated Map Component
